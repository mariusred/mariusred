## I'm Ed 👋

This is my repository for data analytics projects that I have worked on, currently working on, and will be worked on. I come from an engineering background that tries to make sense of problems and implement practical solutions to it. 

**Core tools:** Python (pandas, numpy, seaborn, matplotlib, scikit-learn) · SQL · data modeling · exploratory analysis

### Featured Projects

💡 **Jobstreet Job Listing Data Pipeline and Analytics**

A web scraping job search project that compiles job listings everyday on Jobstreet for data analytics roles (data analyst, data engineer, data scientist, ect.). Utilized Selenium and BeautifulSoup to automate browser control for scraping and parse relevant job information that an individual looks for. Data cleaning (via pandas and regex) fixes data format and handle missing information to prepare the data set for visualization.

💡 **HR Data Analytics for Predicting Leaving Employees**

Final project for the Google Advanced data analytics capstone demonstrating the analysis process when working with employment information. Performed on Jupyter Notebook and Python libraries to walk through each output and discussion. 

#### Project Highlights:

📌 Data preprocessing performed on the given dataset to prepare for machine learning via pandas. 

📌 Explored data trends and points of interests through data visualization and reasoning.

📌 Implemented machine learning algorithms (logistic regression, decision trees, random forest) to predict attrition and compare their metrics performance.
